# freezeclub × Sässis Yoga

Mobil-optimierte Event-Landingpage für das Yoga-Event **freezeclub × Sässis Yoga** in Balingen.

- **Live:** https://freezeclub.github.io/yoga-event/ (GitHub Pages, Branch `main`)
- **Buchung:** https://shop.freezeclub.de/products/freezeclub-x-sassis-yoga-1
- Statisches HTML (`index.html`), `assets/` = Logo.

## Event
Yoga Flow (60 Min., für jedes Level) + Kältekammer-Session im freezeclub Balingen.
Ablauf: Kennenlernen & Tee → 1 h Yoga (eigene Matte mitbringen) → Essen & gesunde Snacks → Kältekammer.

- **Ort:** Wilhelmstraße 45, 72336 Balingen
- **Termine:** Fr 7. August 2026 · Fr 18. September 2026, jeweils 18:00 Uhr
- **Preis:** 79 € pro Person (inkl. Bonus-Gutschein für eine weitere Anwendung)
